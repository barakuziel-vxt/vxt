## Git & Deployment Strategy (MANDATORY - NO EXCEPTIONS)

### ONE RULE TO RULE THEM ALL:
**All code changes go to `main` branch. Deployments use ONLY `push-to-prod.ps1` script. Never touch `prod` directly.**

### What This Means:

1. **User asks to "fix and deploy"**
   - ✅ Step 1: Make changes, commit to `main`
   - ✅ Step 2: Push to `main` with `git push origin main`
   - ✅ Step 3: Tell user: "Run `.\push-to-prod.ps1` to deploy"
   - ❌ Do NOT push to `prod`
   - ❌ Do NOT run `git checkout prod`

2. **User asks to "deploy existing code"**
   - ✅ Tell user: "Run `.\push-to-prod.ps1`"
   - ❌ Do NOT manually merge to prod
   - ❌ Do NOT run any git commands on prod

3. **User asks to change prod branch directly**
   - ✅ Redirect to main: "Changes should go on main first"
   - ✅ Offer workflow: "Commit to main, then run the script"
   - ❌ Do NOT create PRs to prod
   - ❌ Do NOT merge to prod manually

### Why This Matters:

- **GitHub Actions:** Only `prod` branch triggers Azure deployment
- **Safety:** Script is tested, automatic pushes are not
- **Control:** User controls deployments via script, not AI
- **Auditability:** Clear deployment record
- **Multi-session:** All sessions must follow SAME workflow

## Git Operations Reference

### ✅ ALLOWED (Safe Operations):
```bash
git checkout main                    # ✅ Switch to main
git pull origin main                 # ✅ Sync with GitHub main
git add .                            # ✅ Stage changes
git commit -m "message"              # ✅ Commit locally
git push origin main                 # ✅ Push to GitHub main
git log --oneline                    # ✅ View history
git diff                             # ✅ See changes
```

### ❌ FORBIDDEN (Never Do These):
```bash
git checkout prod                    # ❌ FORBIDDEN - use script only
git push origin prod                 # ❌ FORBIDDEN - use script only
git commit directly to prod          # ❌ FORBIDDEN
git merge manually to prod           # ❌ FORBIDDEN - use script
git rebase into prod                 # ❌ FORBIDDEN
```

### ✅ SPECIAL (Script Handles This):
```bash
# Don't run manually - use script:
.\push-to-prod.ps1                   # ✅ ONLY way to update prod
```

## Emergency Procedures

### If Prod Is Broken:

```bash
# Option 1: Revert bad commit on main
git revert <bad-commit-hash>
git push origin main
.\push-to-prod.ps1  # Deploy fix

# Option 2: Reset prod to previous state (rare)
git checkout prod
git reset --hard <previous-good-hash>
git push origin prod --force
```

### If You Accidentally Pushed to Prod:

```bash
# Reset prod back to main
git checkout prod
git reset --hard origin/main
git push origin prod --force

# This is why branch protection exists!
```
